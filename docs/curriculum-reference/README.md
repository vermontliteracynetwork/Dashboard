# Curriculum Reference Folder

Drop reference material here for AI-generated question sets: scanned/exported workbook pages, curriculum PDFs, standards checklists, unit plans, whatever a question set should be grounded in.

**Naming:** one subfolder per subject or unit works best, e.g. `curriculum-reference/math-fractions/`, `curriculum-reference/reading-cvc-words/`. Plain file names, no spaces preferred (use dashes).

**What this is for:** per the Native Game Standard (`docs/NATIVE_GAME_STANDARD.md`), a question set attached to a native game can be teacher-authored, AI-generated from Common Core standards and the class's stated focus areas, or AI-generated by reading files placed in this folder directly. Files here are treated as source material Claudia/Claude should cite from when building a question set, not as content to display to students directly.

Nothing in this folder is itself a game or a question set. It's reference material only.
