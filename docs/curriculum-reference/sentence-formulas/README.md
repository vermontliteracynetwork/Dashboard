# Sentence Formulas — Curriculum Reference

Direct teacher upload, saved here as source material for the Literacy Workspace's Sentence Grammar tile category (see `docs/LITERACY_WORKSPACE.md`).

## `Sentence_Formulas_Template.pdf`

Kayden's own teacher-authored sentence-formula curriculum (36 pages). This is real, ready-to-use content, not a generic reference — pull from it directly rather than inventing new sentence formulas.

**Formula taxonomy** (page 28-31), each with a WHO/ACTION/... slot formula and two worked examples:
- **Basic Action Sentences**: Simple Sentence (intransitive, WHO+ACTION), Simple Statement (transitive, WHO+ACTION+WHAT/WHO), Reflexive Sentence (WHO+ACTION+himself/herself/itself)
- **Descriptive Sentences (linking verbs)**: What Is It? (WHO+is/was+ADJECTIVE), Who/What Is It? (WHO+is/was+NOUN), Where Is It? (WHO+is/was+PLACE), How Does It Feel/Seem? (WHO+feels/seems/looks+ADJECTIVE)
- **Adverbial Sentences**: How Was It Done? (WHO+ACTION+ADVERB), When Did It Happen? (WHO+ACTION+TIME), Where Did It Happen? (WHO+ACTION+PLACE), Why or How Often? (WHO+ACTION+FREQUENCY)
- **Object Sentences**: Who Got What? (WHO+ACTION+INDIRECT OBJECT+DIRECT OBJECT), What Did It Become? (WHO+ACTION+OBJECT+COMPLEMENT), What Did Someone Make/Build? (WHO+ACTION+OBJECT+for+SOMEONE)
- **Existence/Location Sentences**: There Is/Are Something, Here Is/Are Something
- **Command/Request Sentences**: Simple Command ((YOU)+ACTION+OBJECT), Polite Request (Please+ACTION+OBJECT)
- **Question Sentences**: Yes/No Question, Wh- Question
- **Negative Sentences**: Simple Negative (Action), Simple Negative (Description)

Earlier pages (2-3) also build toward a "Complete Basic Sentence" by chaining WHO+ACTION+WHAT+WHERE+WHEN progressively, one new slot at a time — a real, already-built explicit-instruction progression, directly usable as the Sentence Grammar rung ladder instead of inventing a new one.

**Word lists** (pages 5-11, 26), organized by phonics level, each tagged by slot (WHO/WHAT/WHERE/WHEN/ACTION/DESCRIPTION):
- General (untagged phonics level): proper nouns (Mom, Dad, Ms. Kayden, Uncle Bill, Mia), common nouns, locations, time words, verbs, adverbs, adjectives
- CVC word list (cat, dog, hat, cup, etc.), tagged the same way
- VCe (silent-e) word list (ape, bike, cake, home, etc.)
- A third "short vowels/blends" list (skunk, splash, sing, camp, etc.)
- A "Sorted Lists" set (page 26) with fantasy/mythology-flavored proper nouns (King Tut, Zeus, Osiris, Santa, Bigfoot) alongside the everyday ones

**Named recurring characters/mascots** already used in example sentences — worth reusing for tone/continuity rather than inventing new ones: Yoga, Azalea, Xander, Geoff, Moxie ("a gigantic, golden, evil fox" with "a lipcoat and a crabapple"), Miss Kayden. A "Mythology Sentence Formulas" and "Yoga Comic Sentence Formulas" section (page 16) and silly example sentences ("Yoga sublimely teleported his lipcoat to Maximus") confirm this is meant to support genuinely silly, high-interest content, not just plain drill sentences — directly matches the Literacy Workspace's Sandbox/Mad-Libs framing.

**Tools referenced by name in the original document**: "Flippity Manipulatives" and "Flippity Randomizer" (flippity.net — a real, free classroom tool for spinner wheels/randomizers/flashcards). The teacher's own past use of Flippity's randomizer for sentence-formula practice is a concrete, named precedent for the Literacy Workspace's own spin-wheel randomizer feature.

**Presentation formats already explored** in the source doc: horizontal formula layout, vertical formula layout, and a "Sorted Lists" tabular layout — worth referencing when designing the Sentence Grammar tile UI's own formula display.
